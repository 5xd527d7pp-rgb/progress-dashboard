Todo投稿自動化ツール 図解

対象: 今回実装した週次Todoレポートの収集・可視化・配信パイプライン

更新日: 2026-04-26 / ワークフロー: run-todo-report / GitHub Actions: 毎週月曜 08:00 JST

1) 全体アーキテクチャ（入力 → 処理 → 出力）

入力ソース

  • 電話ログCSV（URL同期）
  • 受信メール（IMAPで.eml保存）
  • 打合せメモ（docx/txt/md）
  • イベント情報（business-events.json）

処理パイプライン

  • CSV/メール/議事録を正規化
  • 重複排除 + SN採番
  • 期限整合性チェック
  • 集計JSONとHTMLを生成

出力/配信

  • output/todo-report.html
  • Surgeへデプロイ（公開URL）
  • 要約メールを自動送信
  • ArtifactへHTML保存
入力 変換・判定 成果物 運用ルール

2) 実行シーケンス（run-todo-report）

GitHub Actions / 手動実行ともに、下記の順で直列実行
STEP 0
事前チェック
npm run check-todo-report-setup

必須ENVと入力ファイルの存在を検証。

STEP 1
電話CSV同期
npm run sync-phone-log

URLからraw CSVを取得。失敗時は既存ローカルを利用。

STEP 2
電話CSV取込
npm run import-phone-log

phone-log-todos.jsonへ変換。

STEP 3
IMAP受信巡回
npm run fetch-todo-mails:imap

新着メールのみ.eml保存（UID/重複キー管理）。

STEP 4
ソース解析
npm run analyze-todo-sources

メール/打合せ本文から業務ID・期限・タスク抽出。

STEP 5
統合データ生成
npm run build-todo-report-data

全ソース統合、重複除去、SN採番、警告生成。

STEP 6
HTML生成
npm run generate-todo-report

output/todo-report.htmlを生成。

STEP 7
公開
npm run deploy-todo-report

Surgeへ反映し、URLをtodo-report-url.txtへ保存。

STEP 8
投稿（メール送信）
npm run send-todo-report-email

集計結果と公開URLを関係者へ通知。

※ previewでは最終ステップがdry-run（送信せず本文をログ出力）になります。

3) 運用モード

Preview（検証）

  • コマンド: npm run run-todo-report:preview
  • SMTP必須チェックを緩和
  • Surge反映は実施
  • メール送信はdry-run（誤配信防止）

Production（本番）

  • コマンド: npm run run-todo-report
  • 事前チェック + 全工程を本実行
  • Surge公開URLをメール本文に差し込み
  • 毎週月曜08:00 JSTに自動起動

4) 定常運用チェックリスト

タイミング 確認項目 見る場所 異常時の一次対応
毎週実行後 HTMLビルド時刻が最新か 公開HTMLの「HTMLビルド」行 Actionsログで generate/deploy を再確認
毎週実行後 期限整合性警告の件数 レポート内「期限整合性チェック結果」 対象SNをタスク起票して担当者へ確認
メール未反映時 IMAPで新着を取得できたか data/todo-input/mails/ と実行ログ IMAP認証情報/LOOKBACK_DAYSを見直し
電話ログ欠落時 CSV URLが正常か raw-phone-log.csv と同期ログ 共有設定・ヘッダー列・URLを再確認
配信テスト時 誤送信防止 workflow_dispatch mode=preview previewで動作確認後にproduction実行

5) 必要な設定値（要点）

区分 主なENV/Secrets 用途
入力 TODO_REPORT_PHONE_LOG_CSV_URL 電話連絡CSVの自動同期元
メール取得 TODO_REPORT_MAIL_IMAP_HOST/USER/PASS/... 受信箱からTodoメール取り込み
公開 TODO_REPORT_SURGE_DOMAIN/LOGIN/TOKEN HTMLの公開先ドメインと認証
通知 TODO_REPORT_SMTP_*, TODO_REPORT_MAIL_FROM/TO 要約メールの送信
挙動制御 TODO_REPORT_FAIL_ON_WARNINGS, TODO_REPORT_PHONE_ONLY 警告時の失敗条件・入力ソース制限

この図解は、現行の npm scripts / GitHub Actions / 各Nodeスクリプト実装に合わせて作成しています。
